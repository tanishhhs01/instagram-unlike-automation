## ✨ Overview

**Instagram Unlike Automation** is a lightweight JavaScript automation script designed to speed up the process of unliking Instagram posts.

Instead of manually opening and unliking posts one by one, the script automates the repetitive clicking and scrolling process directly in the browser.

### ⚡ What it does

- 🔄 Automatically scans liked posts
- ❤️ Selects liked posts for removal
- ❌ Automates the unlike process
- 📜 Automatically handles scrolling
- ⏱️ Uses delays to reduce excessive rapid actions
- 📦 Processes posts in batches
- 🖥️ Runs directly inside your browser
